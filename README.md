# Flight Data Analysis and Network Optimization

This project explores large-scale flight transportation data through a combination of statistical analysis, algorithmic optimization, and network science techniques. The objective is to extract meaningful insights from airline operations, evaluate computational performance across different algorithms, and model airport connectivity as a complex transportation network.

The project integrates data processing, graph theory, and algorithm analysis to study flight patterns, airport interactions, carrier performance, and network structures. Multiple datasets containing airport and flight information are parsed and analyzed to construct a comprehensive representation of air transportation systems.

A significant component of the project focuses on algorithmic efficiency. Various sorting and data access algorithms are implemented and benchmarked across datasets of different sizes to evaluate runtime performance and computational scalability. Experimental results are used to compare algorithmic behavior under realistic data workloads.

In addition to classical data analysis, airports and flight routes are modeled as a graph, enabling the application of network analysis techniques to investigate connectivity, centrality, route structures, and transportation efficiency. Visualizations are generated to support the interpretation of network dynamics and operational patterns.
